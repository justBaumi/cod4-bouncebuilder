## Install

For full functionality the tool requires mod tools to be installed.

1. Unzip the latest release into your CoD4 folder
2. Start `BounceBuilder.Ui.exe` from the BounceBuilder folder


## What it does
Choose what kind of things you want in your BounceBuilder. Build and expand your inventory as needed and create your own assortment.

Choose a source map and a location to inject the palette into, then compile your BounceBuilder.

<img width="1872" height="1180" alt="image" src="https://github.com/user-attachments/assets/2beb392d-aab8-4d1f-84d4-5e67984064ac" />


Back up your config_mp.cfg or use a new CoD4 profile. The map modifies your config.

Start your map and hold the USE button to load the BounceBuilder binds. Build your route in game. Hit the save key to save your route into your config.
